# F7 для Yapfast

Здесь всё, что превращает Yapfast в F7. Файлы самого Yapfast не меняются, всё накладывается при сборке.

- `restyle.py`: цвета (F7 Dark и F7 Paper), квадратные углы, шрифт JetBrains Mono, без теней, F7 вместо логотипов.
- `patches/0001-mic-switches.patch`: три переключателя микрофона (эхоподавление, автогромкость, щелчки).
- `assets/`: логотип, иконка приложения, шрифт (лицензия OFL лежит рядом).
- `../.github/workflows/f7-build.yml`: сборка под Windows и публикация в Releases форка.

Обновление: на странице форка кнопка Sync fork, потом Actions > F7 build > Run workflow.
Если сборка падает на шаге "Apply the F7 patches and restyle", автор изменил то место, которое я трогаю. Пришлите текст ошибки.

Проект распространяется по GPL-3.0, шрифт по SIL OFL 1.1.
